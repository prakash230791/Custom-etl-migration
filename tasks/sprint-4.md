## Module: l5_tests.py

### Input
- List of etl-spec blocks from requirements document (same list L2 used)
- Generated PySpark code from L1+L2+L3 (used to understand what functions exist)

### Output
- Dict: `{test_filename: pytest_file_content}`
- One test file per Glue job: `tests/test_{job_name}.py`

### L5 Rules (from §5.5)

1. One test function per transform in §4 of requirements document
2. All tests initially marked `@pytest.mark.xfail(reason="Fill expected_output from source system reference run")`
3. Generate three test functions per transform: standard input, null input, empty input
4. `@xfail` mark removed only by developer after filling expected values
5. Use `pyspark.testing.utils.assertDataFrameEqual` for DataFrame comparison
6. All tests must use `spark` fixture with `SparkSession.builder.master("local[*]")`
7. Use Claude API to generate realistic fixture data for each transform's input schema
8. If API call fails → generate empty fixture with TODO comment; never block output

## Update QA-6

```python
def _run_qa6_test_coverage(self, spec_blocks: list, generated_tests: dict) -> list[dict]:
    """
    QA-6: Verify at least one test function per transform in §4.
    Does NOT block output — emits WARNING only.
    """
    findings = []
    for block in spec_blocks:
        transform_id = block.get("transform_id")
        test_key = f"test_{transform_id}_standard"
        all_test_content = " ".join(generated_tests.values())
        if test_key not in all_test_content:
            findings.append({
                "gate": "QA-6",
                "severity": "WARNING",
                "message": f"No test generated for transform {transform_id}"
            })
    return findings
```
